# Lab 3 starter — Secure and Resilient Services

This folder is the **participant starter** for Lab 3.

It already contains working Lab 1 and Lab 2 code. You add JWT, token relay, a circuit breaker, and tests.

Open the service you are editing in VS Code and follow:

**[LAB-3-GUIDE.md](../LAB-3-GUIDE.md)**

Work in the service folders here and follow the lab guide. This pack has no `solution/` folder.

**Required:** Docker Desktop. You will run Account Service (8081) and Transaction Service (8082) together.
