# Lab 0 — start here

All work this week happens on your **TEKsystems Ablaze virtual machine**, not on your laptop.

1. Find **your name**, Ablaze username, and password in [LAB-ACCESS.md](../../../LAB-ACCESS.md). Do not use `MSMICR26-TD`.
2. In a browser, open **https://my.ablazedesktop.com** and sign in.
3. Wait until the **Windows desktop** appears (taskbar, Start, icons).
4. **Inside that desktop**, open Visual Studio Code → PowerShell (Ctrl+`). Sign in to **GitHub Copilot Free** in VS Code (every student VM and the instructor VM already have it).
5. Follow **[LAB-0-GUIDE.md](LAB-0-GUIDE.md)** from Step 1 — clone, Copilot sign-in, Java 21, Docker, and the check script all run **on the VM**. Clone as the **short folder** `%USERPROFILE%\MD287`. If VS Code used the long repo name, rename it — **[Tip — short folder `MD287`](../../TIP-SHORT-FOLDER.md)**.

Do not install Java, Maven, or Docker on your personal laptop for this course.

The check script (after you clone) is `tools/check-environment.ps1`.
