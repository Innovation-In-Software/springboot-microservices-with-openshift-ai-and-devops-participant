1. Find your name, Ablaze username, and password in [LAB-ACCESS.md](../../../LAB-ACCESS.md). Do not use `MSMICR26-TD`.

4. Copy-paste **[LAB-0-GUIDE.md](LAB-0-GUIDE.md)** on the VM. Folder: `%USERPROFILE%\MD287`.

If `MD287` already exists, do not clone and do not run `mklink`. Use `cd $env:USERPROFILE\MD287` then `git pull`.
